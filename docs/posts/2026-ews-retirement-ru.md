# EWS отключают. Пока все переписывают скрипты, покажу десктопный клиент к Graph, который работает от тикета, а не от эндпоинта

*Черновик для Хабра, хаб «Системное администрирование». От первого лица, от мейнтейнера.*

1 октября 2026 года Exchange Web Services в Exchange Online перестаёт
поддерживаться: тем, кто не занёс свои EWS-приложения в allow list, Microsoft
выставит `EWSEnabled = false`, а в апреле 2027 протокол выключат окончательно.
Параллельно с 8 апреля этого года начал умирать Reporting Web Service, на
котором сидели `Get-MessageTrace` и `Get-MessageTraceDetail`, — трассировка
писем переезжает в Graph. Ни то, ни другое не новость, но в сумме это значит,
что сейчас многие админы пересматривают, что вообще ходит в их тенант, и куча
«сейчас запущу старый скрипт» ломается.

Я делаю небольшую open-source десктопную утилиту, которая целиком живёт на
Microsoft Graph. Хочу рассказать, что она умеет для админа, которому надо
закрыть тикет, а писать под каждый тикет PowerShell не хочется. И честно
перечислить, чего она не умеет, — потому что это ограничения самого Graph, и
вы упрётесь в них с любым инструментом.

## Что это

SwissKnife for MS Graph — десктопный клиент под Windows / macOS / Linux
(бэкенд на Go, фронт на React, собрано на Wails). Работает через вашу
собственную регистрацию приложения: либо app-only с client secret, который
лежит только в системном хранилище (Credential Manager / Keychain / Secret
Service), либо delegated через device code. Токен не покидает Go-процесс и не
попадает в веб-слой. Любая запись — через набранное руками подтверждение и в
локальный аудит-лог; есть глобальный read-only, чтобы сначала просто
посмотреть. Лицензия MIT.

Главное архитектурное решение — интерфейс собран **вокруг задач, а не вокруг
эндпоинтов**. Каждая страница — сетка плиток, по одной на работу, названную
так, как её называет тикет: «добавить в приватный канал», «почему человек не
может войти», «выдать Иванову такой же доступ, как у Петрова». Ctrl+K, пара
слов (по-русски или по-английски — ищет одновременно по обоим), Enter — и вы
на той форме, которая это делает. Рядом с каждой формой — короткая заметка о
том, где кусается Graph: в приватный канал можно добавить только участника
команды, динамические и Exchange-группы через Graph не меняются, снятие
последней лицензии убивает ящик примерно через 30 дней. Сырые таблица / JSON
/ дерево никуда не делись, они в один клик; просто это больше не первое, что
вы видите.

Несколько задач из списка:

- **Зеркало доступа.** Читает у двух людей группы, админ-роли, команды,
  приватные каналы и лицензии, показывает разницу (в том числе то, что есть
  только у *целевого* — полезно знать, кто носит доступ, которого нет ни у
  кого), и докидывает недостающее. Только добавление, подтверждение имени,
  всё в журнале.
- **Плейбук увольнения.** Блокировка, отзыв сессий, снос методов MFA,
  автоответ, пересылка через правило входящих, скрытие из GAL, передача
  владения группами и командами, отмена встреч, которые уволенный
  организовал, удаление из групп, retire/wipe устройств в Intune, удаление
  зарегистрированных устройств, копирование OneDrive на стороне сервера в
  чужой OneDrive, снятие лицензий, удаление. Каждый шаг отчитывается
  отдельно; на 403 приложение пишет, какое именно разрешение не выдано, а не
  «Forbidden».
- **Аудит, который отвечает на вопрос.** Входы одного человека, сначала
  неудачные, с кодом ошибки Entra по каждой строке, за выбранный период.
- **Conditional Access как факты.** К кому применяется политика, кто
  исключён, какие приложения, что требует. JSON свёрнут.
- **Уборка.** Дубликаты и раздутая история версий по OneDrive и всем
  библиотекам SharePoint, с оценкой размера по сайтам.
- **Трассировка писем** (в следующем релизе). «Куда делось письмо?» через
  новый эндпоинт `/admin/exchange/tracing/messageTraces`, с автоматическим
  созданием service principal для Transport Data Platform — без него Graph
  отвечает 401/403 даже при выданном разрешении, и из документации это
  неочевидно.
- Ну и обычное: пользователи, лицензии, группы, Teams, чаты, почта, файлы,
  Intune, ключи BitLocker, истекающие секреты регистраций приложений, отчёты
  использования, состояние сервисов и сырой Graph-плейграунд с историей.

## Русский язык — не приклеенный сбоку

Приложение двуязычное с первого коммита интерфейса, английский — основной,
русский — полноценный, не автоперевод. Это касается не только подписей:

- палитра Ctrl+K ищет по ключевым словам на обоих языках сразу — «канал»,
  «пароль», «уволенного», «такой же доступ как у» находят нужную плитку
  независимо от того, какой язык стоит в настройках;
- заметки о подводных камнях Graph рядом с формами, предупреждения
  («без лицензии ящик удалится через ~30 дней»), названия шагов плейбука и
  тексты ошибок — переведены;
- отчёты использования Microsoft 365 показываются с переведёнными названиями
  и периодами;
- в тестах есть проверка паритета: если ключ появился в `en.ts` и не появился
  в `ru.ts`, сборка падает. Так что русская локаль не может отстать от
  английской «на один релиз».

Если найдёте кривой перевод — это issue на пару строк, правится за минуту.

## Чего нет, и почему

Ограничения Graph, а не приложения. Лучше знать заранее.

- **Конвертации ящика в общий.** В Graph такого API нет. Поэтому плейбук
  увольнения сделан под два запуска: сначала всё, кроме лицензий, затем вы
  руками конвертируете ящик в Exchange admin center, затем — только лицензии,
  причём перед снятием есть предварительный шаг, который проверяет тип ящика.
- **Бэкап чатов Teams требует одобрения protected API.** Чтение чатов
  app-only — это `Chat.Read.All`, который Microsoft одобряет отдельно по app
  id, admin consent недостаточно. Пока одобрения нет — шаг падает с 403, и
  приложение так и пишет.
- **Скрытие из GAL у AD-синхронизированных** не срабатывает: атрибут ведётся
  on-prem. Приложение показывает ошибку Graph; правится в AD.
- **Сборка под macOS пока без подписи.** В DMG лежит скрипт «Fix Quarantine»
  и однострочник с `xattr`. Windows-сборка проверяется minisign-подписью
  контрольных сумм, но не Authenticode, так что SmartScreen при первом запуске
  предупредит. Оба пункта в планах; оба стоят денег.
- **Экспорт/импорт ящиков** через новые Graph API (GA с мая) в приложении
  пока нет.

## Как попробовать

- Windows: `winget install Nemu-x.SwissKnifeGraph` (на момент публикации
  манифест может ещё быть на модерации — актуальный статус в README), либо
  установщик / portable exe со страницы релизов.
- Arch: `yay -S swissknife-graph-bin`.
- macOS и Linux (deb / rpm / AppImage / tar.gz): прямые ссылки на
  https://github.com/Nemu-x/SwissKnife-for-MS-Graph/releases. Контрольные
  суммы подписаны minisign, публичный ключ в репозитории.

Нужна регистрация приложения в Entra; в wiki есть матрица разрешений по
функциям и минимальный набор для старта. Совет: включите read-only,
покликайте, потом выдавайте write-разрешения только под те задачи, которыми
реально пользуетесь.
